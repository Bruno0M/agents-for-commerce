# Servidor MCP em .NET, hospedado em VPS própria (Oracle Cloud)

O servidor MCP usa o SDK oficial C# (`modelcontextprotocol/csharp-sdk`), hospedado em VPS própria na Oracle Cloud — não local, não como função serverless, não hospedado no próprio Deco Studio. Escolhido porque os organizadores do hackathon sinalizaram que quanto mais próximo de um ambiente de produção real, melhor para o pitch; uma VPS com deploy próprio reforça isso mais do que uma função hospedada.
